# Exploratory Data Analysis (EDA)

This directory is intended for Jupyter notebooks and data analysis.

## Adding Data
To analyze your CSV files:
1. Place your `.csv` files into this `eda` folder.
2. Create a new Jupyter Notebook (`.ipynb` file) here.
3. Use `pandas` (e.g., `import pandas as pd; df = pd.read_csv('your_data.csv')`) to load and explore your data.
